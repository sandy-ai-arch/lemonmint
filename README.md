## 💳 Payment Gateway System (`js/checkout.js`)

- **Multi-Gateway Tabs**:
  1. **UPI & Dynamic QR Code**: Authentic simulated QR code with instant scan, UPI app badges (GPay, PhonePe, Paytm, BHIM), and UPI ID input.
  2. **Credit & Debit Cards**: Card number, expiry, CVV, Cardholder name, with SSL verification simulation.
  3. **NetBanking**: Major bank selection (HDFC, ICICI, SBI, Axis).
  4. **Pay via WhatsApp**: Generates and sends a direct payment link to the user's WhatsApp.
- **Promo Codes**:
  - `BANANA20`: 20% discount on any package.
  - `LEMONMINT`: Flat ₹1,000 / $15 off.
  - `FRESHSTART`: 15% discount.
- **Victory Screen**: Celebratory fanfare sound, +500 🍌 XP, instant digital receipt with transaction ID (e.g. `TXN_LM_98241`), and a 1-click **"Send Receipt to WhatsApp"** confirmation button.
